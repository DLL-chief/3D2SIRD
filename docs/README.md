# docs/ — центр архитектурной правды

Эта папка отвечает на вопрос «почему система устроена так, как устроена»,
в отличие от `README.md` в корне (он отвечает «как запустить и куда идти»).

## Что где искать

- **`architecture.md`** — модули, поток данных от 3D-модели до PNG,
  инварианты. Читать, когда меняется взаимодействие модулей или добавляется
  новый.
- **`api_contracts.md`** — форматы данных между модулями: карта глубины,
  параметры генератора, формат паттерна. У проекта нет сетевого API, но
  контракт между `depth/` и `sird/` — это граница, через которую два модуля
  можно разрабатывать и тестировать независимо. Обновлять при ЛЮБОМ
  изменении.
- **`adr/`** — architecture decision records. Принятый ADR не редактируется
  задним числом; для пересмотра решения заводится новый файл со ссылкой на
  старый.

## Правило актуальности

Правка кода, которая меняет модули, поток данных или контракт между ними,
обязана обновить соответствующий файл в `docs/` **в том же PR**.
