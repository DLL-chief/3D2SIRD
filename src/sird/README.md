# sird — генератор автостереограммы

## Назначение

Чистая функция `generate(depthMap, params) → ImageData` по алгоритму
Thimbleby–Inglis–Witten (1994) плюс обёртка для запуска в Web Worker.
Контракты входа/выхода — `docs/api_contracts.md`.

## Инварианты этого модуля

- **Не импортирует Three.js** и ничего из `scene/`, `depth/`, `ui/`.
  Проверяется на ревью.
- Детерминирован при фиксированном `seed` — на этом держится тест с
  эталонным изображением.
- Ширина/высота выхода строго равны входной карте.
- Формула сепарации: `sep(z) = round(E · (1 − μz) / (2 − μz))`, где `z` —
  значение карты (0 — далеко, 1 — близко), `E` — межзрачковое расстояние
  в пикселях, `μ` — сила рельефа. При `crossEyed` вместо `z` берётся `1 − z`.
- Окклюзия учитывается по оригинальной статье (проверка видимости точки
  из обоих глаз) — без неё стереограмма даёт «двоение» на границах объекта.

## Точка входа для чтения

`src/sird/generate.js` — сам алгоритм; `src/sird/worker.js` — обёртка
`postMessage`; `src/sird/pattern.js` — источники паттерна (шум / текстура).

## Известные ловушки

- **Период паттерна на фоне — `round(E/2)`, а не `E`.** Формула сепарации
  при `z = 0` даёт `round(E/2)`: именно с таким шагом повторяются точки на
  фоне. При чётном `E` период `E` тоже выполняется (как кратный), на этом
  держится тест периодичности — с нечётным `E` он бы не прошёл. Отсюда же
  следствие для паттерна-картинки: из текстуры шириной `E` в кадр попадает
  ровно половина столбцов, поэтому `ui/` масштабирует её под `round(E/2)`
  (замерено в `__tests__/pattern-image.test.js`).
- **Порядок операций при перестановке ссылок `same`.** В ветке «новая пара
  ближе, чем записанная» (`same[left] > right`) старую ссылку нужно
  сохранить (`right = старый same[left]`) ДО перехода к следующей итерации,
  иначе хвост цепочки теряется и на границах объекта появляется мусор.
- **Проверка окклюзии у краёв карты.** Индексы `x ± t` выходят за карту;
  их надо трактовать как фон (`z = 0`, не заслоняет), а не клампить и не
  пропускать проверку.
- **В Node нет `ImageData`.** Тесты (vitest) работают в node-окружении без
  DOM, поэтому `generate` возвращает совместимый объект
  `{width, height, data}`, если глобального `ImageData` нет.
- **Эталон — текстовый ASCII PBM (P1), не PNG.** Без зависимостей-кодеков,
  диффабелен в PR и переживает текстовые API (у агента без git-пуша
  бинарник через GitHub API не пролезает без порчи). Формат тянет только
  строго ч/б картинку — ровно случай `{type: 'noise', color: false}`;
  для цветного эталона формат придётся менять. Кодек — `__tests__/pbm.js`,
  перегенерация: `node src/sird/__tests__/make-fixture.mjs`.
