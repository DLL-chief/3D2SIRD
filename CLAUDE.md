# CLAUDE.md — параметры для Claude Code

@import AGENTS.md

Этот файл дополняет `AGENTS.md` тем, что специфично именно для Claude Code.
Общие правила стека, стиля кода, коммитов и работы со `STATUS.md` — в
`AGENTS.md`, здесь они не дублируются.

## Специфика окружения Claude Code

- **Разрешение на PR/мёрдж:** агент сам создаёт ветку и PR, но не мёрджит
  без ревью владельца. Прямой пуш в `main` запрещён.
- **Проверки перед сдачей задачи:** `npm run build` должен проходить без
  ошибок. Когда появятся тесты для `src/sird/` — `npm test` обязателен.
- **Ограничения окружения:** приложение проверяется в реальном браузере
  (Chrome/Firefox последних версий) — WebGL-рендер и Web Worker нельзя
  полноценно проверить в Node. Если у агента нет браузера, он честно пишет
  в PR, что визуально не проверял, а не утверждает обратное.
- **Порядок работы над кодом с нуля:** сначала `src/sird/` (чистый
  алгоритм, тестируется на синтетической карте глубины — сфера, ступеньки),
  потом `src/depth/`, потом `src/scene/` и `src/ui/`. Порядок зафиксирован
  в `STATUS.md`, беклог.

## Как агенту ориентироваться в репозитории

1. Прочитать `AGENTS.md` — правила.
2. Прочитать `STATUS.md` — текущее состояние работы.
3. При работе в конкретном модуле — прочитать его локальный `README.md`
   (`src/<module>/README.md`).
4. При архитектурном вопросе — `docs/architecture.md` и `docs/adr/`.
5. При вопросе о формате данных между модулями (карта глубины, параметры
   генератора) — `docs/api_contracts.md`.
