## Ближайший беклог (в порядке выполнения)

1. `sird/`: паттерн из пользовательской текстуры — тайлинг готов
   (см. «Сделано»), осталось масштабирование под E на стороне `ui/` и
   тест на паттерне-картинке.
2. `depth/`: рендер сцены Three.js в render target с линейной глубиной,
   нормализация по bounding box модели (не по near/far камеры), чтение в
   `Float32Array`.
3. `scene/`: загрузка GLB (drag&drop + встроенная демо-геометрия),
   OrbitControls.
4. `ui/`: слайдеры (сила рельефа μ, межзрачковое расстояние E, размытие
   карты глубины), превью карты глубины, кнопка «сгенерировать», экспорт
   PNG; подключить готовый `sird/worker.js` вместо временного стенда
   (`index.html` + `src/main.js` тогда убрать/переделать).
5. GitHub Actions: сборка + деплой на GitHub Pages.
6. Маркеры-подсказки над картинкой для наведения фокуса; режим
   перекрёстного взгляда в UI (флаг `crossEyed` в `sird/` уже есть).

## Отложено (не в MVP)

- GPU-версия генератора (шейдер/WebGPU) для стереограммы в реальном времени
  при вращении модели — см. ADR-003.
- Калибровка E под физический размер пикселя экрана.
- Загрузка OBJ/STL.
