## Ближайший беклог (в порядке выполнения)

1. `sird/`: генератор по алгоритму Thimbleby–Inglis–Witten на CPU:
   `(depthMap, params) → ImageData`, паттерн — случайные точки. Проверить на
   синтетической карте (полусфера над плоскостью) — стереограмма должна
   «читаться» глазами.
2. `sird/`: паттерн из пользовательской текстуры (тайлинг полосы шириной E).
3. `depth/`: рендер сцены Three.js в render target с линейной глубиной,
   нормализация по bounding box модели (не по near/far камеры), чтение в
   `Float32Array`.
4. `scene/`: загрузка GLB (drag&drop + встроенная демо-геометрия),
   OrbitControls.
5. `ui/`: слайдеры (сила рельефа μ, межзрачковое расстояние E, размытие
   карты глубины), превью карты глубины, кнопка «сгенерировать», экспорт PNG.
6. Web Worker для генератора, чтобы UI не замерзал.
7. GitHub Actions: сборка + деплой на GitHub Pages.
8. Маркеры-подсказки над картинкой для наведения фокуса; режим
   перекрёстного взгляда (инверсия глубины).

## Отложено (не в MVP)

- GPU-версия генератора (шейдер/WebGPU) для стереограммы в реальном времени
  при вращении модели — см. ADR-003.
- Калибровка E под физический размер пикселя экрана.
- Загрузка OBJ/STL.
